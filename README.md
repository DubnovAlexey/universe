## 7. Interactive Controls, URL Parameters & Local Setup

### Interactive Controls
* **Left Mouse Button / Touch Hold / `Space`:** Open the `BREACH LENS` at the pointer position, refract surrounding starlight along the unstable rim, open the coordinate grid cells, and reveal the deep `Z4` sub-quantum neural layer underneath.
* **Mouse Hover on Act 05 Manifesto Rows:** Trigger a localized quantum character re-spin on the static authorship and technology lines before they settle back into place.
* **Bottom Control Dock / Keys `1`–`5`:** Switch phases (`01.VOID`, `02.GENESIS`, `03.EVOLUTION`, `04.COLLAPSE`, `05.SINGULARITY`) or toggle `PAUSE`, `AUTO: ON/OFF`, `AUDIO: ON/OFF`, `METRICS`, `TOPOLOGY`, `TERMINAL`, and `X-RAY`.

### URL Query Parameters for Deterministic Testing
* `?seed=104729` — Lock the `SplitMix32` PRNG seed for bit-exact deterministic replay across browsers and OS platforms.
* `?quality=high|medium|low` — Override the automatic frame-time `QualityGovernor`.
* `?debug=1` — Boot with the full-height right telemetry waterfall (`Layers 2–4`) and `State Digest` inspector active from `t = 0s`.
* `?kiosk=1` — Gallery exhibition mode (automatically triggers a clean `ResourceLedger` reset and restarts the cycle 12 seconds after the Act 05 odometer card locks).

### Local Development Commands
1. Clone repository and install workspace dependencies:
   `git clone https://github.com/DubnovAlexey/universe.git && cd universe && npm install`
2. Start Astro + React 19 + WebGPU development server (`http://localhost:4321`):
   `npm run dev:frontend`
3. (Optional) Recompile Rust symplectic physics kernel to WebAssembly:
   `npm run build:wasm`
4. (Optional) Launch Python FastAPI binary WebSocket server on port `8000`:
   `cd backend && pip install -r requirements.txt && uvicorn main:app --reload --port 8000`
5. Build static production bundle for GitHub Pages:
   `npm run build --workspace=frontend`

Каждое кольцо дышит и изменяется во всех своих частях, взаимодействуя с окружающими энергетическими структурами: где-то фронт волны вырывается вперёд, где-то изгибается дугой или уходит в глубокое затухание.
2. **Полный отказ от прямых фоновых «палок» в пользу полевых и спиральных структур:**
   Прямолинейные диагональные полосы на фоне полностью заменены на глубокие фазозависимые явления, взаимодействующие с остальными частями сцены:
   * **в фазе `01. VOID`** — полупрозрачные полевые облака и редкие пробегающие от края до края тонкие квантовые сигналы;
   * **в фазе `02. GENESIS`** — многослойные спиралевидные рукава межзвёздной пыли и газовые завихрения по прообразу галактик `Андромеда (M31)` и `NGC 3169`;
   * **в фазах `03. EVOLUTION` — `05. SINGULARITY`** — дышащие полевые градиенты, вихревые волокна и мигрирующие нейронные импульсы.
3. **«Обратная сторона Вселенной» под клеточками линзы `BREACH LENS` (Эшелон `Z4`):**
   При наведении и нажатии кнопки мыши раскрывается круглая оптическая мембрана с нестабильным живым контуром и координатными клеточками. В эти моменты под клеточками открывается более глубокая структура (`Z4`) — «изнанка Вселенной» с внутренними нейросетевыми передвижениями, суб-квантовыми импульсами и глубинными токами.

   * **Живой контур как у мышки при нажатии:** Все прямые линии и прямоугольные углы таблиц убраны. Границы правой панели оформлены такими же нестабильными, плавно двигающимися и дышащими волновыми линиями, как окружность `BREACH LENS` вокруг курсора мыши при нажатии.

Время от времени отдельные нижние цифры плавно отделяются и падают вниз — как падающие звёзды на небе или капли (`кап-кап` с разной естественной частотой), — а на их месте тут же прокручиваются и зажигаются новые значения, сохраняя полную читаемость всех данных.

## 4. Роли языков и структура репозитория

* `README.md` — полная двуязычная архитектурная и пользовательская документация проекта (`EN / RU`).
* `docs/study_materials/MATHEMATICAL_AND_ASTROPHYSICAL_MODELS.md` — фундаментальное двуязычное математическое и астрофизическое руководство со всеми формулами и выводами (`EN / RU`).
* `physics_engine/src/{lib.rs, gravity.rs, breach_math.rs, memory.rs}` — вычислительное ядро на **Rust / WebAssembly**: симплектический интегратор `Velocity Verlet`, фазовая синхронизация Курамото, математика мембраны `BREACH LENS` и хеширование состояния `FNV-1a`.
* `backend/core/{graph_logic.py, stress_solver.py, singularity.py}` и `backend/utils/binary_packer.py` — вычислительное ядро на **Python 3 (Pyodide / FastAPI)**: генерация когнитивного графа `NEXUS` (остов MST, граф Габриэля, закон Мюррея), расчёт топологических метрик и бинарная упаковка пакетов `UNVS`.
* `frontend/src/engine/{renderer.ts, pipeline.ts}` и `frontend/src/engine/webgpu/{illusion.wgsl, truth.wgsl, breach.wgsl}` — графическое ядро **WebGPU / WGSL и High-DPI Canvas 2D**: деформирующиеся кольца `RS Puppis`, спиралевидные пылевые облака `M31`, корона `NGC 6543`, суб-квантовый слой `Z4` под клеточками мыши и рефракция линзы.
* `frontend/src/layers/{Layer2_Metrics.tsx, Layer3_Topology.tsx, Layer4_Terminal.tsx, Layer5_CipherFinale.tsx}` — живые интерфейсные слои **React 19**: полноразмерный правый цифровой водопад со звездопадом падающих цифр и контуром линзы, а также дышащая финальная карточка с монохромной строкой одометра.
* `frontend/src/utils/audioSync.ts` и `frontend/public/audio/cosmic_ambient.mp3` — гибридная звуковая подсистема **Web Audio API + MP3** с мгновенным стартом на нулевой секунде и спектральным анализом.

## 5. Честная матрица режимов исполнения (Truth Policy)

Интерфейс никогда не имитирует поддельные метрики. Все статусы в правой панели (`LAYER_02` — `LAYER_04`) отражают реальное состояние среды исполнения:

| Режим работы | Активный вычислительный контур | Подлинные статусы в правой панели телеметрии |
| :--- | :--- | :--- |
| **A. Static GitHub Pages (Базовый)** | Полностью автономная работа в браузере без внешних серверов: физика в `Rust/WASM` (или эталонном `TS FALLBACK`), граф `NEXUS` — в локальном `Web Worker`. | `WASM READY` (или `TS_FALLBACK • CLIENT_ONLY`), `WEBGPU READY` (или `CANVAS2D READY`), `AUDIO: ON` |
| **B. Static + Pyodide (Python в браузере)** | Фоновая инициализация интерпретатора Python в Web Worker после первого кадра для выполнения `graph_logic.py` непосредственно на клиенте. | `PYODIDE LOADING → PYODIDE READY` (или `PYTHON: FALLBACK` на устройствах с малым объёмом ОЗУ) |
| **C. Static + FastAPI Server (Серверный)** | Подключение по бинарному WebSocket к серверу FastAPI; статус `SERVER CONNECTED` зажигается строго после рукопожатия `hello` (`schemaVersion` + `heartbeat`). | `SERVER CONNECTED`, `[python/graph_logic.py]`, `[rust/gravity.rs]` |

## 6. Быстрый старт и команды запуска

1. Клонировать репозиторий и установить зависимости:
   `git clone https://github.com/DubnovAlexey/universe.git && cd universe && npm install`
2. Запустить сервер разработки фронтенда (`http://localhost:4321`):
   `npm run dev:frontend`
3. (Опционально) Скомпилировать физическое ядро `Rust → WebAssembly`:
   `npm run build:wasm`
4. (Опционально) Запустить сервер `Python FastAPI` на порту `8000`:
   `cd backend && pip install -r requirements.txt && uvicorn main:app --reload --port 8000`
5. Собрать статический билд для публикации на GitHub Pages:
   `npm run build --workspace=frontend`
