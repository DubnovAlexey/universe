# QA и V1 — состояние реализации и покрытия

Дата: 25 октября 2026 года. Версия: `v2.5.0`. Подтверждённые дефекты проверены по исходникам; повторяющиеся формулировки объединены в независимые пункты ниже.

<!-- НАЧАЛО РАЗДЕЛА 1. СТАТУС -->
## 1. Текущий статус

Изменения QA от 25.10 реализованы в исходниках: кириллический hover, нормализованный шаг общего кадра, доступный канонический текст, подписки DOM-анимаций вместо отдельных RAF, очистка неиспользуемого состояния и расширение реальных WASM/Python проверок. Текущий набор — 61 модульная проверка (39 TS + 9 Python + 13 Rust) и 6 интеграций реального WASM. Финальный `npm run verify:all` после исправления compact-layout и наблюдения заголовка завершился с кодом 0 под Node `22.23.4` с `NODE_ENV=production`: Python verifier, 61 модульная, 6 WASM-интеграций, typecheck, Astro `7.4.2` build и Pages artifact. Свежий `npm audit` сообщает 0 уязвимостей.

Дополнительно прошли строгая проверка неиспользуемого TypeScript, форматирование Rust и разрешение 112 относительных imports/resources; осиротевшие исходники в проверенных путях не найдены. WASM в собранном Pages-артефакте побайтово совпадает с проверенным бинарником, размер — 54 975 байт. Эти проверки не прибавляются к числу unit tests.

Выборочный просмотр последней production-сборки:

- Desktop `1440×900`: карточка примерно в `y=62…381`, выше центра `450`; все три действия доступны, радиус контейнера `36px`, внешний box-shadow отсутствует, горизонтального переполнения нет.
- Mobile `507×684`: карточка в `x=8.4…498.8`, `y=58.5…313.7`, ниже заголовка с нижним краем `49.9` и выше центра `342`. Все три действия в `x=21.2…486.0`, `y=203.7…298.5`, `tabIndex=0`. Высота содержимого и client height равны `256`, ширина карточки — `491`, документа — `507`: обрезки содержимого и горизонтального скролла не обнаружено.
- Узкий `320×568`: карточка в `x=8.24…311.76`, `y=59.14…355.86`, её scroll/client height равны `297`, ширина — `304`, ширина документа — `320`. Все действия в `x≈21…299`, `y=245.86…340.69` доступны без обрезки. Здесь центр частично перекрыт из-за высоты контента; ограниченный подъём сохраняет полную видимость вместо универсального обещания свободного центра.
- Принудительный TS fallback (`?wasm=0`, viewport шириной `1280`): подтверждены `TS_FALLBACK`/`CLIENT_ONLY`, fallback-статус native-модуля, видимая GENESIS и египетский glyph pool. В журнале просмотренного запуска warning/error нет.
- Два независимых чтения на паузе дают идентичный transform; активные hover-сеансы прекращаются. Tab переводит фокус на действие репозитория. Кириллический визуальный текст меняется, доступный канон остаётся стабильным; видны египетские и математический supplementary глиф `𝛁`.
- Вручную выбраны все пять фаз при native `READY`, наблюдались естественные новые циклы. Нажатие/отпускание canvas открывает и закрывает BREACH с соответствующими событиями. В просмотренном запуске warning/error не зарегистрированы.

Это выборочный smoke, а не непрерывная запись 108 секунд. Слышимость/повтор аудио, Safari/iOS, системный reduced motion, полный blur/hidden-tab сценарий и воспроизводимый performance baseline остаются отдельной приёмкой.

Последняя опубликованная ревизия `b60c995` успешно прошла [CI #45 — build и deploy](https://github.com/DubnovAlexey/universe/actions/runs/40129807958). Это подтверждённый результат опубликованной ревизии, а не проверка ещё не опубликованных изменений 25.10.

Текущие официальные Actions `checkout/setup-node/setup-python@v7`, `upload-pages-artifact/deploy-pages@v5` сохраняются. Workflow использует Node `^22.23.4`, оба manifests — `engines.node >=22.23.4`, Astro — `7.4.2`. Возврат к диапазону `22` или `>=22.12.0` снова допустил бы несовместимый Node patch. Переменная принудительного переключения старых Actions на Node 24 не требуется.

Исторический локальный результат 24.10: 48 модульных (27 TS + 8 Python + 13 Rust), 5 WASM-интеграций, typecheck, Astro/Pages и audit 0. Тогда выборочный smoke на `1440×900`/`507×684` подтвердил доступность карточки, ссылки, фокус, паузу и supplementary глифы; прежние прямоугольники карточки не описывают новую геометрию 25.10. Этот просмотр не подтверждал непрерывные 108 секунд, слышимость/повтор аудио, Safari/iOS, системный reduced motion или performance baseline.

`npm run verify:all` сохраняет guard `verify:repo`, Python verifier/unittest, native Rust, TS typecheck/verification suite, реальную WASM-сборку/интеграции, Astro build и Pages artifact. Существующие проверки не удалялись.

## 4. Предложения и выбранные границы

| Предложение | Решение |
|---|---|
| Возвратить breathEnv=0 на каждой паузе | Выбран пропуск неизменных кадров на общей подписке: положение карточки фиксируется без скачка к нейтральному transform, а reduced motion применяет статичное состояние однократно |
| Добавить seed всем классам или заменить знак hash-функцией | Для устранения скачка выбран минимальный вариант, сохраняющий builders и геометрию fixtures. Другие алгоритмы изменили бы изображение и не требуются исправлением |
| Кешировать контур линзы по углам с шагом 5° | Отдельная оптимизация по профилированию; необходимость не подтверждена. Текущие вызовы не выполняют расчёт на каждый пиксель экрана |
| Оставить разные округления и лишь ослабить assert до `0.01` | Введён общий численный контракт и точное сравнение общей fixture; допуск сам по себе не устранил бы различие правил |
| Свести TS/Rust ABI в один TS-файл | TS-файл не проверяет Rust автоматически. Для этого нужен генератор общей схемы либо межъязыковые ABI-тесты. Сейчас действуют реальные ABI/WASM проверки; генератор не реализован |
| Перенести все scripts в корень | Корневые npm wrappers уже работают с `frontend/scripts/`; перенос не нужен. Исправляется полнота отслеживаемой ревизии, добавлен guard |
