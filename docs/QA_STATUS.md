# QA и V1 — состояние реализации и покрытия

Дата: 24 октября 2026 года. Версия: `v2.5.0`. Подтверждённые дефекты проверены по исходникам; повторяющиеся формулировки объединены в независимые пункты ниже.

<!-- НАЧАЛО РАЗДЕЛА 1. СТАТУС -->
## 1. Текущий статус

QA-исправления и V1 реализованы в исходниках. Финальный `npm run verify:all` после всех изменений завершился с кодом `0`: **48 модульных проверок — 27 TypeScript, 8 Python, 13 Rust**, отдельно **5 интеграций реального WASM**, typecheck, Astro `7.4.2` build и Pages artifact. В финальном терминальном прогоне warning/error не зарегистрированы; `npm audit` сообщает **0 уязвимостей**.

Выборочный просмотр последней production-сборки подтвердил:

- Desktop `1440×900`: первое появление карточки и её сохранение в следующем цикле `01 → 02`; после подъёма карточка занимает `y=99.4…420.6` при центре экрана `450`. Все три действия видны, адреса ссылок проверены.
- Клавиатура: Tab переводит фокус на действие репозитория; декоративный текст меняется, aria-label остаётся точным каноническим. Пауза прекращает активные hover-сеансы, восстанавливает текст и замораживает положение.
- Mobile `507×684`: карточка находится в `x=7.2…500`, `y=172…428`; все три действия видны и имеют `tabIndex=0`, их прямоугольники находятся в `x=20…487`, `y=318…413`. Ширина документа равна viewport (`507`), горизонтального переполнения нет. На низком экране частичное пересечение центра допустимо: приоритет — полная видимость и доступность контента.
- Supplementary глифы, включая египетские, видны в runtime; Rust сохраняет `READY` после изменения active count `820 → 590`. В журнале финального просмотренного запуска warning/error отсутствуют.

Это выборочный smoke. Непрерывные 108 секунд, слышимость/повтор аудио, Safari/iOS, системный reduced motion, браузерное событие скрытия вкладки и воспроизводимый performance baseline этим не подтверждаются.

`npm run verify:all` сохраняет Python verifier/unittest, native Rust, TS typecheck/verification suite, реальную WASM-сборку/интеграции, Astro build и Pages artifact. В начало добавлен `npm run verify:repo`: он проверяет отслеживание исходников/fixtures и файлов запуска из npm scripts; guard также включён в CI.

Последний проверенный удалённый [CI #43 на `f2ef49b`](https://github.com/DubnovAlexey/universe/actions/runs/40107715957) завершился ошибкой из-за отсутствия `frontend/scripts/build-wasm.mjs` в опубликованной ревизии. Локальные scripts и guard подготовлены; успешный новый удалённый CI требует новой опубликованной ревизии и отдельного результата запуска.

## 2. Подтверждённые исправления QA

| Пункт | Реализация | Проверка и граница |
|---|---|---|
| Скачок изгиба NEXUS между перестроениями | `01_void.ts`: seed участвует только у `AXON_TRUNK`; `BRIDGE/DENDRITE` используют сумму id, как TS/Python builders | Реальный путь rebuild → intermediate update → rebuild при нечётном seed проверяет все три класса. Изолированный возврат старой формулы ломает именно эту регрессию |
| Замороженная truth-reveal маска BREACH | `stressState.ts`: в `getDeformedLensRadiusAtAngle` передаётся текущее `simulationTimeSec` | Фиксированная точка пересекает движущуюся кромку; ожидаемый reveal сравнивается с радиусом того же времени. Возврат вызова без времени ломает эту регрессию |
| Разные десятичные округления TS/Python | `roundGraphDecimal` и `round_decimal`: `floor(v * scale + 0.5) / scale` для двух/трёх знаков во всех публикациях графа | Положительные/отрицательные ties и опубликованные координаты рёбер проверяются. Ties идут к `+∞`; например `-1.125 → -1.12`. JS `Math.round` не округляет отрицательные ties от нуля |
| Недостаточное покрытие паритета | Fixture6 сохранена; общий `frontend/src/tests/fixtures/nexusParity24.json` хранит transport-входы и ожидаемый результат для двух языков | RNG потребляет x/y/z/vx/vy/energy в исходном порядке. Точно сравниваются все 40 edge objects, controls/LUT/radii, 24 degrees и семь метрик. Это сильнее допуска `0.01` |
| Геометрия и метрики fixture24 | 23 trunk, 11 bridge, 6 dendrite; `avgDegree=3.33`, `C=0.384`, `diameterHops=8`, `avgPathLength=3.29` | 24 узла расширяют покрытие локального окна Gabriel. Они не проверяют лимит 36 хабов, прореживание входов `N>260` и выборочный BFS |
| Семантика BFS и LUT в документации | Шаг стартов `max(1, floor(Nactive / 28))`; LUT суммирует четыре хорды, затем инвертируется по интервалам | BFS полный до 55 активных узлов включительно, sampling начинается с 56; это не жёсткий предел 28 стартов. Curved-LUT regression проверяет концы и четыре интервала и отличает arc mapping от raw Bezier t. Идеально постоянная скорость не заявляется |
| Строка аудиотелеметрии | `Layer2_Metrics.tsx` использует прямой шаблон `${t.audioStatus} (${t.silenceRmsDb.toFixed(1)} dBFS)` | Исходник проверен; декоративные глифы не подменяют реальные значения |
| Шапка/структура TS verification suite | Назначение и тематические комментарии описывают фактический набор; устаревшее «16» не используется как текущий итог | Фактический счётчик выполнения — `27/27`; V1 добавляет шесть проверок к 21 проверке после QA |
| Зависимости и инструменты сборки | Astro обновлён до `7.4.2`, оба manifests требуют Node.js `>=22.23.4`; Actions обновлены для Node 24, Cargo incremental отключён для устранения hardlink warning, атрибуты LF закреплены | `npm audit`: 0 уязвимостей. Финальный локальный build и pipeline прошли без warning/error; новый удалённый CI ещё не подтверждён |
| Карта файлов и счётчики документов | В Bible указаны `favicon.png`, `compute_reference_total_energy()`, четыре `frontend/scripts`, новые V1-модули/тесты и общий JSON | Текущий итог 48 + 5 синхронизирован; исторические 27 и 35 + 5 явно относятся к прежним состояниям |

## 4. Предложения и выбранные границы

| Предложение | Решение |
|---|---|
| Добавить seed всем классам или заменить знак hash-функцией | Для устранения скачка выбран минимальный вариант, сохраняющий builders и геометрию fixtures. Другие алгоритмы изменили бы изображение и не требуются исправлением |
| Кешировать контур линзы по углам с шагом 5° | Отдельная оптимизация по профилированию; необходимость не подтверждена. Текущие вызовы не выполняют расчёт на каждый пиксель экрана |
| Оставить разные округления и лишь ослабить assert до `0.01` | Введён общий численный контракт и точное сравнение общей fixture; допуск сам по себе не устранил бы различие правил |
| Свести TS/Rust ABI в один TS-файл | TS-файл не проверяет Rust автоматически. Для этого нужен генератор общей схемы либо межъязыковые ABI-тесты. Сейчас действуют реальные ABI/WASM проверки; генератор не реализован |
| Перенести все scripts в корень | Корневые npm wrappers уже работают с `frontend/scripts/`; перенос не нужен. Исправляется полнота отслеживаемой ревизии, добавлен guard |
| Запретить любой UTF-16 surrogate в regex | Проверяется отсутствие одиночных surrogate, а не запрет корректных пар supplementary code point |

## 5. Открытая приёмка и следующие этапы

- Расширить выборочный desktop/mobile smoke: полный blur-сценарий, missing-glyph fallback на других ОС, системный reduced motion, событие скрытия вкладки и дополнительные низкие viewport.
- Просмотреть непрерывный первый 108-секундный цикл и начало второго, рабочие ссылки, звук после жеста и границу повторения MP3; Safari/iOS остаётся отдельной средой.
- Измерить p50/p95 на одинаковых устройстве, seed, viewport и профиле после прогрева. Разовые FPS в интерфейсе не считаются baseline.
- Получить новый успешный удалённый CI после публикации полной ревизии.
- V2 (общий экранный transform/глубина), V3 (декоративные переходы), настоящий Worker по измерениям и полезный WebGPU-проход остаются планом. Крупное разделение renderer/CSS — отдельный последний этап; оно не проводилось.
