# ADR-001 — вычислительные модули и единое состояние

Статус: принято.

## Контекст

UNIVERSE совмещает художественную хореографию, численные модели, интерактивную оптику и диагностические представления. Разные языки полезны при чёткой ответственности и воспроизводимом стыке данных.

Результат физического шага должен влиять на итоговую геометрию до её публикации. Координаты Canvas, графа NEXUS и `SceneBufferSoA` происходят из одних particle-объектов; диагностический digest не заменяет этот контракт.

## Решение

- **Astro** формирует статическую оболочку для GitHub Pages.
- **TypeScript** управляет временем, художественными целями, синхронным графом NEXUS и резервной физической реализацией.
- **Rust/WASM** исполняет общую модель Курамото и контрольных орбит `REF64` через raw C ABI v1, а отдельный optional ABI формирует объёмную геометрию Уробороса.
- **Canvas 2D** рисует основные пять фаз и резервное представление объёмного эпизода. DOM/SVG представляет управление и технические слои.
- **Web Audio API** предоставляет воспроизведение и общий снимок музыкальных огибающих.
- **Python** служит независимым численным эталоном, локальным API и средством проверки.
- **WebGPU/WGSL** исполняет отдельный проход `ouroboros.wgsl`: перспективные ядра с глубиной и мягкий свет на прозрачном холсте. Остальные WGSL-файлы остаются спецификациями. Проверка адаптера WebGPU не означает успешную отрисовку; `READY` требует компиляции, offscreen draw/readback и первой проверенной отправки кадра.

## Контракты

### Порядок кадра

Provider рассчитывает фазы до художественных целей. Итоговые координаты читаются Canvas, квантуются для NEXUS и публикуются в SoA. Изменение provider не должно создавать скрытую вторую геометрию после публикации.

### Шаг и состояние provider

Положительный шаг допускается до `0.05 с` и делится на равные подшаги не более `0.004 с`. Неположительный шаг и нулевое активное число не продвигают время. `f64` используется для времени и метрик, `f32` — для массивов.

Загрузка WASM асинхронна. Позднее подключение переносит актуальные фазы, частоты, reference-орбиты, начальную энергию и накопленное время. Native-шаг принимается только после проверки статуса и конечности данных. TS-зеркала обновляются целиком; отказ возвращает расчёт к последнему принятому состоянию. Отклонённый upload требует discard provider со стороны host.

### Физические роли

Kuramoto-фазы влияют на видимые цели. Velocity Verlet рассчитывает отдельные консервативные орбиты; их `ΔE/E₀` не приписывается всей художественной сцене. Скалярный BREACH export представляет фиксированный оптический reference, а экранное векторное преломление остаётся TypeScript.

### Визуальные сигналы

Один опубликованный снимок связывает фазу, нормализованный шаг кадра, аудио, Kuramoto и stress. Декоративные потребители не создают собственных часов, повторной интеграции физики или второго анализатора. Пауза, скрытие вкладки, restart и reduced motion имеют явную политику.

### Декоративная объёмная геометрия

Форма использует отдельный буфер до 3072 записей по восемь `f32`: позиция, нормаль, размер и материал. Rust и TypeScript реализуют один детерминированный контракт; host проверяет optional ABI, память и результат до использования. Дополнительная геометрия собирается из части экранных источников; исходное облако сохраняет видимость и движение. Морфинг не изменяет физику, NEXUS и `SceneBufferSoA`. WebGPU и Canvas читают согласованную геометрию с разными способами освещения.

Эпизод связан с часами подъёма собранной визитки и возвращением формы в поле в первой фазе. Перед ручным или автоматическим переходом `05→01` сохраняется фактическая степень сборки и время ориентации; распыление продолжается от показанного состояния. Эпизод не создаёт шестую фазу и сохраняет 108-секундный цикл. Единственный RAF остаётся у `UniverseRenderer`; ресурсы GPU освобождаются при отказе и снятии страницы, а проверка поколения отклоняет устаревшую асинхронную инициализацию.

### Проверка границ

Raw ABI, указатели, размеры, статус шага и загруженное состояние проверяются host. TS-типы не выполняют автоматическую проверку Rust-структур. Общие fixtures и реальные WASM-интеграции проверяют стык независимо от деклараций типов.

## Последствия

Сцена работает без Python-сервера и без поддержки WebGPU. Rust можно загрузить позже или заменить TS fallback без разрыва принятого состояния. Независимый Python reference остаётся полезным в численных проверках без загрузки интерпретатора в браузер.

Стоимость этого решения — поддержка согласованных реализаций, явных контрактов и проверок переноса состояния. Любая новая асинхронная вычислительная граница должна учитывать порядок результатов, seed/restart и устаревшие ответы. Производительность требует измерения на конкретном устройстве; сам выбор языка не гарантирует ускорения.
