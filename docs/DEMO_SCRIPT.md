# 🎬 Сценарий демонстрации и проверки UNIVERSE (v2.5)

Этот документ содержит краткий сценарий знакомства с проектом для двух аудиторий: **зрителей** (визуальный тур) и **системных архитекторов / CTO / преподавателей** (техническая проверка).

---

## 1. Визуальный тур (60 секунд)

1. **Автоматический старт (`01.VOID` -> `02.GENESIS`):**
   * Откройте страницу проекта на GitHub Pages (`https://dubnovalexey.github.io/universe/`) или локально (`http://localhost:4321/`).
   * С первой секунды запускается сцена рождения Вселенной из Точки Нуля с живыми дышащими кольцами светового эха по мотивам цефеиды `RS Кормы`. Любой клик или касание экрана (на компьютере или смартфоне) включает непрерывный космический саундтрек `cosmic_ambient.mp3`.
2. **Интерактивная линза `BREACH LENS` (зажатие кнопки мыши или клавиша `Space`):**
   * Нажмите и удерживайте левую кнопку мыши в любой точке космоса и поводите курсором.
   * Вокруг курсора раскроется упругая мембрана преломления света, обнажающая геодезическую сетку рентгена и глубинный суб-квантовый слой `Z4` («обратную сторону Вселенной»).
3. **Прямой переход к финалу и визитке (`05.SINGULARITY`):**
   * Нажмите кнопку **`05.SINGULARITY`** в нижней панели (или дождитесь 79-й секунды цикла).
   * Наблюдайте рождение короны «Кошачьего глаза» (`NGC 6543`) и Чёрной дыры, которая затем по спирали сожмётся в яркую микро-точку и без паузы раскроется в голографическую визитку **`DUBNOV ALEXEY`**.
4. **Переход в профиль GitHub и работа на фоне:**
   * В визитке (а также в правом нижнем углу экрана) доступны прямые кнопки перехода на главную страницу профиля **[ ↗ GITHUB PROFILE : DUBNOV ALEXEY ](https://github.com/DubnovAlexey)** и в репозиторий проекта **[ ↗ PROJECT REPOSITORY ](https://github.com/DubnovAlexey/universe)**.
   * Когда цикл пойдёт на следующий круг, визитка останется полупрозрачно парить поверх космоса — достаточно навести на неё мышь в любой момент, чтобы она стала полностью яркой.

## 2. Инженерный тур и команды проверки (25 автоматических проверок)

### Проверка телеметрии в реальном времени
* В правой колонке «Цифрового водопада» (`LAYER_02`, `LAYER_03`, `LAYER_04`) отображаются реальные замеры времени кадра (`FPS / P95`), истинный относительный дрейф энергии в интеграторе `Velocity Verlet` (`ΔE/E₀`), параметр синхронизации Курамото `r(t)`, число рёбер графа `NEXUS` (`MST`, `Gabriel`, `Murray`), выборочная оценка диаметра `EST. DIAMETER / PATH (BFS)`, 32-битный хеш состояния `State Digest`, полная таблица всех 8 модулей `IntegrationRegistry` и счётчики ресурсов `ResourceLedger`.
* Нажатие кнопки **`🔬 X-RAY`** (или клавиши `5`) включает полноэкранный инженерный рентген с парящими выносками узлов (`ID#... [модуль]`).

### Команды автоматической проверки из терминала

    # 1. CLI-проверка математического паритета Python-ядра (PRNG, пакет 'UNVS', граф NEXUS, оптика BREACH)
    python -B -m backend.main --verify

    # 2. Запуск 6 модульных тестов Python (unittest)
    python -B -m unittest discover -v

    # 3. Запуск 5 модульных тестов физического крейта Rust
    cd physics_engine && cargo test && cd ..

    # 4. Строгая проверка типов TypeScript во всём фронтенде
    npm --prefix frontend run typecheck

    # 5. Запуск набора регрессионных тестов фронтенда (14 инвариантов, включая 5-ю фазу и 10x Restart)
    npm --prefix frontend run test

    # 6. Сборка статического продакшен-бандла для GitHub Pages
    npm --prefix frontend run build
